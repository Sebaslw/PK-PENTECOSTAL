VERSIÓN 2.0.10 - INSTALADORES (recomendados) - NO NECESITAN NODE.JS
  Descárguelos gratis en https://sebaslw.github.io/pk-pentecostal.io/

  WINDOWS 10 / 11 (64 bits)
  · PK-PENTECOSTAL-Instalador-2.0.10.exe -> doble clic, "Siguiente".
      Crea accesos directos en el Escritorio y en el menú Inicio.
      Se desinstala desde Configuración -> Aplicaciones.
      SE ACTUALIZA SOLO (desde 2.0.3): avisa, descarga la versión nueva y
      la instala encima, sin desinstalar. Sus datos se conservan.
      Si Windows dice "Windows protegió su PC": Más información ->
      Ejecutar de todas formas.
  · PK-PENTECOSTAL-Portable-2.0.10.exe   -> no se instala (memoria USB).
      No se actualiza solo: descargue la nueva desde la página.

  MAC (Intel y Apple M1/M2/M3/M4)
  · PK-PENTECOSTAL-2.0.10-mac.dmg -> ábralo y arrastre PK-PENTECOSTAL a
      Aplicaciones. La primera vez: clic derecho -> Abrir -> Abrir.
      (macOS 15 o más nuevo: Ajustes del Sistema -> Privacidad y
      seguridad -> "Abrir igualmente".)
      Avisa cuando hay versión nueva y abre la página para descargarla.

  LINUX (Ubuntu, Mint, Debian y otros)
  · PK-PENTECOSTAL-2.0.10-linux-amd64.deb -> doble clic e Instalar, o
      sudo apt install ./PK-PENTECOSTAL-2.0.10-linux-amd64.deb
      SE ACTUALIZA SOLO (pide su contraseña para instalar la nueva).
  · PK-PENTECOSTAL-2.0.10-linux-x86_64.AppImage -> Propiedades -> Permitir
      ejecutar como programa, y doble clic. SE ACTUALIZA SOLO.
      Si no abre (Ubuntu 24.04): use el .deb o agregue --no-sandbox.

  Al abrirlo: si ya estaba abierto solo muestra la ventana; si el puerto
  8888 lo usa otro programa, elige otro libre (sin cerrar ese programa).
  Datos del usuario (se conservan al actualizar y al desinstalar):
      Windows instalado -> %APPDATA%\PK-PENTECOSTAL
      Windows portable  -> carpeta "PK-PENTECOSTAL datos" junto al .exe
      Mac               -> ~/Library/Application Support/PK-PENTECOSTAL
      Linux             -> ~/.config/PK-PENTECOSTAL
  Venía de la versión de carpeta (1.x)?  Alt -> Archivo ->
      "Importar datos de una versión anterior..." (guarda un respaldo antes).
  Registro de eventos: Alt -> Archivo -> Ver registro de eventos.

ABRIR EL PROGRAMA
---------------------------------------------------------------------
WINDOWS (dos formas, igual que el Proyektor original)
  1) PK-PENTECOSTAL.vbs  -> sin ventana negra. Muestra "Iniciando..."
                            y abre el panel en el navegador.
  2) PK-PENTECOSTAL.bat  -> con ventana negra: muestra las direcciones
                            y, si algo falla, el motivo.
  Acceso directo con el logo en el Escritorio:
     doble clic en "Crear acceso directo (Windows).vbs" (solo una vez).
  Si el programa ya está abierto, volver a abrirlo solo muestra el panel.

DIRECCIÓN DEL PANEL:  http://pkipuc.localhost
  Proyector:          http://proyector.pkipuc.localhost
  Si otro programa usa el puerto 80, el programa usa solo
  http://pkipuc.localhost:8888 (y el proyector :8889).
  Si otro programa usa el 8888, se elige solo el siguiente libre
  (queda anotado en BSPK\puerto.json).
  La dirección antigua http://localhost:8888 sigue sirviendo: lleva a la
  nueva y pasa sus ajustes (OBS, textos, Biblia elegida, idioma).
  Si su navegador no abre *.localhost, se queda en la antigua.
  Los celulares usan la IP de la red, por ejemplo http://192.168.1.20:8888

LINUX
  En una terminal, dentro de la carpeta "Proyektor - 64Bits":
     chmod +x iniciar-linux.sh        (solo la primera vez)
     ./iniciar-linux.sh
  Para tenerlo en el menú de aplicaciones:  ./iniciar-linux.sh --instalar

macOS
  Doble clic en "iniciar-mac.command".
  La primera vez: clic derecho > Abrir. Si dice que no tiene permisos,
  en Terminal:  chmod +x iniciar-mac.command

iPHONE / iPAD (y celulares Android)
  El programa corre en el computador; desde el iPad o el celular se
  CONTROLA por Wi-Fi (misma red). Abra en Safari la dirección
  "En la red local" que muestra la ventana negra o la pestaña
  OBS > URLs, por ejemplo  http://192.168.1.20:8888/
  Compartir > "Añadir a pantalla de inicio" lo deja como una app con el
  logo de PK-PENTECOSTAL.
  (La primera vez, Windows puede preguntar si permite el acceso en la
  red: responda "Permitir" en redes privadas.)

CERRAR
  Botón ⏻ (arriba a la derecha del panel), o cerrar la ventana negra
  si lo abrió con el .bat.

IMPORTANTE: no abra el Proyektor original al mismo tiempo; los dos usan
el puerto 8888.

OBS STUDIO
---------------------------------------------------------------------
  Fuentes > + > Navegador. Ancho 1920, Alto 1080. URL:
    http://pkipuc.localhost/capa                          Rótulos + Banner (recomendado)
    http://pkipuc.localhost/capa?solo=overlay             Solo rótulos (nombres)
    http://pkipuc.localhost/capa?solo=banner              Solo banner (versículos/letras)
    http://pkipuc.localhost/salida?modo=obs               Tercio inferior clásico
    http://pkipuc.localhost/salida?modo=pantalla          Pantalla completa con fondo
    http://pkipuc.localhost/salida?modo=pantalla&fondo=0  Pantalla completa transparente
    http://pkipuc.localhost/salida?modo=chroma            Fondo verde (ATEM, vMix)
  O conecte OBS (pestaña OBS) y pulse "Añadir la capa..." para crearla sola.

  Control de OBS desde el panel (OBS 28 o superior):
    En OBS: Herramientas > Ajustes del servidor WebSocket > Habilitar.
    En el panel: OBS > Conectar. Con OBS en este mismo computador, el
    programa lee solo el puerto y la contraseña de OBS (desde la 2.0.4).
    OBS en otro computador: engranaje ⚙ > Buscar OBS en la red (o la IP) >
    contraseña > Guardar y conectar. La capa y el stinger se crean en OBS con
    la IP de este computador. Permita OBS en el Firewall de ese equipo.
    Si la capa deja de verse (el router cambió la IP de este computador),
    pulse otra vez "Añadir la capa": se corrige sola. Mejor: IP fija en el router.

  Canciones: todas salen con el mismo tamaño de letra. Una estrofa larga se
  reparte en varias diapositivas (Estilo > Líneas por diapositiva, 6).
    Permite: estado y botón TRANSMITIR, escenas con miniaturas, cambio con
    Stinger, transiciones, cambio automático de escena, cámaras, audio
    (volumen, silencio, vúmetros, añadir fuentes).

PROYECTOR / TV DE LA IGLESIA
  Botón "📽 Proyectar" sobre el monitor "AL AIRE · Pantalla".
    - Chrome / Edge: la primera vez pide permiso para "administrar
      ventanas en todas las pantallas": responda Permitir. Así se abre
      sola en la 2ª pantalla y a pantalla completa.
    - Otros navegadores: lleve la ventana al proyector y haga doble
      clic (o tecla F / F11) para pantalla completa.
    - Desde la ventana del proyector también funcionan las flechas,
      Espacio, B, H y 1..9.
    - "⏹ Detener" cierra la ventana del proyector.
  (También en OBS > URLs > "Abrir ventana de proyector".)

ATAJOS DE TECLADO
---------------------------------------------------------------------
  Clic                 Mandar al aire
  Shift + clic         Varios versículos juntos
  Flechas / Espacio    Siguiente / anterior (pasa de capítulo solo)
  1..9                 Ir a la estrofa N de la canción
  Esc                  Quitar texto del aire
  B                    Pantalla negra
  H                    Ocultar texto (deja el fondo)
  Ctrl + K             Buscar referencia (Ej: "jn 3 16", "sal 23", "1 co 13:4-7")
  Ctrl + S             Guardar ajustes del módulo OBS

---------------------------------------------------------------------
MÓDULO OBS (pestaña OBS)
---------------------------------------------------------------------
  OVERLAY · Rótulos
    - Un clic pone el nombre al aire, otro clic lo quita.
    - Lista (agregar, editar, color, ordenar, pegar varios), Ajustes
      (texto por defecto), Reloj ON = se quita solo con el Temporizador.
    - Luces, Fondo, Temporizador, Borde, Stinger, Plantilla, aparición.
    - Vista previa: arrastre el rótulo para moverlo.
  BANNER
    - Fondo de imagen o video, efectos (partículas, nieve, bokeh,
      estrellas, rayos), texto, colores, alto, desenfoque, transición.
    - Los cambios se ven al instante; GUARDAR los conserva.
    - OVERLAY y BANNER ocultan sin borrar.

DATOS
---------------------------------------------------------------------
  Usa las carpetas del Proyektor original: biblias, cancioneros, fondos
  y css/font. Agregue imágenes o videos a "fondos"; los que suba desde
  el panel quedan en fondos/Subidos.
  CARPETA PRIVADA BSPK (al lado de PK-PENTECOSTAL; no se sube a GitHub):
    config.json (ajustes, rótulos, claves de celulares), obs/ (stingers,
    logos, sonidos, videos), respaldos/ (copias al editar canciones),
    fondos/ (fondos subidos y videos pesados) y traductor/.
  Si viene de una versión anterior, el programa mueve todo ahí solo al abrirse.
  Para copiar el programa a otro computador con sus ajustes, copie también BSPK.

DISEÑOS DE OVERLAY (pestaña OBS > OVERLAY > "Diseños de overlay")
  Toque un diseño y se aplica al instante: su imagen (sin modificarla) y
  los textos acomodados en su lugar, del tamaño justo para que quepan.
  Nombre = el rótulo al aire · Cargo = su cargo o el texto del grupo ·
  Texto adicional = evento o tema (los diseños de 3 líneas lo muestran).
  Si edita un nombre o grupo que está al aire, se actualiza solo.
  "+ Agregar": suba su propia imagen PNG 1920x1080 con fondo transparente;
  el programa detecta solo dónde van los textos. "Ajustar los textos de este
  diseño" permite moverlos o cambiar color, alineación y fuente.
  MOVER LOS TEXTOS (como en ProyectoRP): en "Vista previa · Overlay" cada
  texto aparece en un recuadro. Arrástrelo para moverlo; la esquina dorada
  cambia su tamaño; con el recuadro elegido, las flechas lo mueven 1 px
  (Shift = 10 px) y los botones ▲◀▶▼ 10 px. ⟲ = distribución original.
  Se ve al instante y al soltar queda guardado (OBS se actualiza solo).
  VENTANA INTERACTIVA: botón "⧉ Abrir ventana interactiva" (debajo de la vista
  previa). Pantalla grande donde se arrastra cada módulo hasta su sitio: textos
  del diseño, rótulo clásico y cuenta regresiva. OBS lo ve al momento.
  Guías (centro y zona segura), imán, flechas (Shift = 10 px), Ctrl+Z deshacer.
  GUARDAR conserva la posición del rótulo y de la cuenta (los textos de los
  diseños se guardan solos).

CUENTA REGRESIVA (pestaña OBS > OVERLAY > "Cuenta regresiva")
  "EMPEZAMOS EN 10:00" sobre la transmisión. Botones 5/10/15/30 min, minutos
  a mano o "hasta las HH:MM"; +1 / -1 min y Detener. Al llegar a cero muestra
  un mensaje ("¡Bienvenidos!") o se oculta. Sale en /capa o en una fuente
  aparte: http://pkipuc.localhost/cuenta

BANNERS LATERALES (pestaña OBS > BANNER > Ajustes > Diseño)
  Diseños de ProyectoRP tal cual y su versión PK-PENTECOSTAL: franja lateral
  con logo y el versículo o la letra dentro.

ATAJOS DE STINGER: S = stinger completo · Shift+S = cubrir / descubrir.

RESPALDO (botón 💾 Respaldo, abajo en el pie de página)
  Exportar: un .zip con ajustes, rótulos, claves, stingers, laterales y
  respaldos (carpeta BSPK + obs). Importar: lo restaura en otro computador
  (antes guarda una copia de lo actual). Luego cierre y abra el programa.

VERSIÓN NUEVA: el botón con el número de versión (pie de página) consulta
  GitHub. Una vez al día avisa solo si hay una versión nueva.

STINGERS (pestaña OBS > STINGERS)
  Transiciones a pantalla completa con logo, sonido y efectos.
  En OBS agregue la fuente de navegador http://pkipuc.localhost/stinger
  (o pulse "Añadir el stinger a todas las escenas").
  "Cambio de escena con stinger": al tocar una escena, el stinger cubre,
  OBS cambia y el stinger se retira. "Importar desde ProyectoRP" trae sus
  stingers, logos, sonidos, fuentes y el overlay tal cual.

CONTROL DESDE EL CELULAR (Android / iPhone)
---------------------------------------------------------------------
  1. Conecte el teléfono al MISMO Wi-Fi que el computador.
  2. En el panel del computador presione "📱 Celular".
  3. Escanee el código QR con la cámara del teléfono y toque el enlace.
     El teléfono queda vinculado (no hay que instalar nada).
  En el teléfono:
    - Elegir / Diapositivas / Monitor cambian de vista.
    - La barra de abajo: ◀ anterior, Negro, Ocultar, Limpiar, ▶ siguiente.
    - Para tenerlo como app: menú del navegador > "Agregar a pantalla
      de inicio".
  Seguridad: solo los teléfonos que escanearon el QR pueden cambiar lo
  que se proyecta. "Desvincular todos" (en la ventana del QR) genera un
  código nuevo y desconecta a todos los teléfonos.
  WI-FI PROPIO (cualquier lugar: hoteles, redes que bloquean, sin Wi-Fi)
    En la ventana del QR elija "🛜 Wi-Fi propio" > "Crear Wi-Fi propio".
    El computador crea la red PK-PENTECOSTAL. Escanee el QR ① para
    unirse a esa red y luego el QR ② para abrir el panel.
    Se apaga solo al cerrar el programa (y se restaura la zona Wi-Fi
    que Windows tenía configurada). Solo en Windows; hasta 8 teléfonos.

  Si el teléfono no logra abrir la página:
    - Revise que ambos estén en el mismo Wi-Fi (no en datos móviles).
    - Si el computador tiene varias redes, elija otra en "Red:".
    - Permita el programa en el Firewall de Windows. Como administrador:
      New-NetFirewallRule -DisplayName "PK-PENTECOSTAL (celulares en la red local)" -Direction Inbound -Protocol TCP -LocalPort 8888 -RemoteAddress LocalSubnet -Action Allow
    - Algunas redes públicas (hoteles, wifi de invitados) bloquean que
      los equipos se vean entre sí; use otra red o el router propio.

IDIOMAS (Español latino · English UK · English US)
---------------------------------------------------------------------
  Pestaña "🌐 Idiomas": elija el idioma y todo el programa cambia al
  instante (computador y celulares).
  Biblias: en inglés cada versión usa su pareja real en inglés:
    RV1960 -> King James (KJV) · NVI, NTV -> World English Bible (WEB)
    DHH, TLA, PDT -> Bible in Basic English (BBE)   (dominio público)
  Las citas salen en inglés ("John 3:16"); se puede buscar "juan 3:16"
  o "jn 3:16" en cualquier idioma.
  Canciones: en inglés se proyecta la traducción si existe (marca EN).
  Para agregar o corregir una traducción: Editar canción ->
  "Letra en inglés". Las traducciones se guardan aparte en
  cancioneros/traducciones/ (los cancioneros originales no cambian).
  Traducción automática (sin internet): en "🌐 Idiomas" pulse
  "🤖 Traducir todas las canciones". Traduce en este computador las
  canciones que no tienen traducción (marca EN·auto). En el editor de
  canciones, el botón "🤖 Traducir automáticamente" traduce una sola.
  Las canciones nuevas se traducen solas al guardarlas.
  Cancioneros en inglés como archivo (EE. UU. y Reino Unido):
  cancionerosCANCIONES<nombre> (English US).txt / (English UK).txt
  Instalar el traductor (una vez, con internet):
    node PK-PENTECOSTAL/traductor/instalar.js
  Para volver a generarlos: en la carpeta PK-PENTECOSTAL	raductor
  ejecute  node exportar.js
